# VK Moderation Bot

Бот для личного состава модерации VK.

## Возможности
- Отчёты сотрудников
- Доказательства наказаний
- Личная карточка
- Предупреждения / выговоры
- SQLite база данных

## Установка

```bash
pip install -r requirements.txt
```

Заполни `config.py`

```python
TOKEN = "TOKEN"
OWNER_ID = 123456789
```

## Запуск

```bash
python bot.py
```
